# 品牌官网导航

导航模块的“导航布局与交互”可选择“品牌官网导航”。经典模块仍为默认值，不迁移或改写现有商户。

品牌模式支持独立 Logo 上传、品牌名称、导航底色／文字色／强调色／下拉底色、突出显示一个现有页面作为主按钮，以及为服务中心和语言按钮预留顶部空间。字体沿用原模块字体设置。Logo 不再借用背景图字段。

电脑可悬停、点击箭头或用键盘展开子菜单；手机及窄编辑画布自动变为折叠菜单。Escape、菜单外点击和页面选择会收起相应菜单，隐藏菜单不会保留可聚焦按钮。吸顶仅在公共页面实际滚动容器中启用，不把编辑器工具栏固定在网站顶部。

子栏目只引用导航中已有页面，不增加套餐页面数量、不创建页面、不跳到外部网址。最多 32 个子栏目；删除页面后失效引用不显示。主按钮不挂载子菜单。修改可通过既有“导航栏对齐”同步到当前方案其他页面。

渲染与编辑器共用同一品牌导航组件。配置通过原云端草稿、发布和模板复制流程保存；模板校验继续拒绝缺失页面引用。预约、联系资料、业务权限、登录和其他模块逻辑不变。

参考布局与交互：[Ilusiona](https://ilusiona.com/)。只借鉴导航结构，不复制其 Logo、图片、栏目资料或专有素材，也不新增无真实内容的栏目。

验证：`src/lib/siteNavigation.test.ts`、`src/lib/websiteTemplateLibrary.test.ts`，以及已纳入原模板浏览器 CI 的 `scripts/leisure-presentation-browser-acceptance.mjs`。浏览器使用隔离的模拟数据，不创建真实预约、不读取用户登录信息。
