# FAOLLA 本机静默打印助手

用于经营中心积分兑换小票的专业静默打印方案。网页负责提交小票内容，本机助手负责调用 Windows 打印管道，不弹浏览器打印窗口。

## 启动

在收银电脑项目目录运行：

```powershell
npm.cmd run print-helper
```

默认监听：

```text
http://127.0.0.1:17658
```

可指定端口：

```powershell
node scripts/faolla-print-helper.mjs --port=17658
```

## 推荐安装位置

建议固定解压到：

```text
C:\FAOLLA\打印助手
```

解压后双击 `安装开机自启动.bat`，会为当前 Windows 用户创建开机自启动，并立即后台启动助手。

## 后台配置

进入 `经营中心 > 打印机`：

1. 开启 `启用本机助手静默打印`
2. 助手地址保持 `http://127.0.0.1:17658`
3. 点击 `检测助手`
4. 点击 `读取本机打印机`
5. 打印机名称留空会使用 Windows 默认打印机，也可以填写如 `XP-80C`
6. 点击 `测试打印`
7. 保存配置

## 打印机要求

- Windows 已安装打印机驱动
- 打印机在系统里可以正常打印测试页
- 58mm/80mm 热敏打印机都可用，纸宽在后台配置

## 自动切纸

后台开启 `结尾自动切纸` 后，网页会请求本机助手使用 ESC/POS RAW 模式打印。小票内容结束后，助手会先按 `切纸前走纸行数` 送出空白行，再发送切刀指令：

- 半切：`GS V 66 0`，适合 XP-80C 这类带半切刀的热敏打印机
- 全切：`GS V 65 0`，只在打印机明确支持全切时使用

普通浏览器打印仍由 Windows 驱动控制分页和切纸，不能精确指定切刀位置。

## 小票边距

`经营中心 > 打印机` 里的 `内容边距(mm)` 是小票内容自己的边距，不依赖浏览器打印预览里的手动边距。

- 浏览器测试打印：通过打印页 CSS 的 mm padding 生效。
- 本机助手静默打印：文本模式会补空行和左侧空格；ESC/POS 模式会设置左边距和可打印区域，并按左右边距限制 Logo 宽度。
- 建议浏览器打印预览里的边距保持 `无` 或 `默认`，实际留白统一在后台配置。

## 小票水印

后台的小票水印支持文字和内置图形符号，按斜向重复方式显示在票面下层。水印属于浏览器打印/预览功能；本机静默打印助手走文本或 ESC/POS RAW，不做斜向背景叠印。

## 页头 Logo

后台上传 `页头 Logo` 后，浏览器打印会直接使用图片；本机助手静默打印会在 ESC/POS RAW 模式下下载图片并转换为单色位图，打印在小票页头。Logo 下载或转换失败时，不会阻断小票文字打印。

网页端会缓存当前收银页已转换过的 Logo，同一台收银电脑连续打印时不会每单重复转换。

## 打印队列

1.5.2 起，本机助手会对 `/print` 请求做串行队列处理。同一台收银电脑连续快速结算多单时，打印任务会按收到的顺序执行，避免并发任务同时抢占 Windows 打印机。

`/health` 会返回当前队列长度，打印结果里会包含 `queue.waitMs` 和 `queue.durationMs`，方便后台日志排查慢打印。

## 开机自启动

1.5.2 起，本机助手支持自启动状态接口：

- `GET /autostart`：查看当前用户是否已启用开机自启动。
- `POST /autostart`，请求体 `{ "enabled": true }`：启用开机自启动并后台启动助手。
- `POST /autostart`，请求体 `{ "enabled": false }` 或 `{ "action": "disable" }`：取消开机自启动。

这个自启动只对当前 Windows 用户生效，不需要管理员权限。

## 安全边界

- 助手只监听 `127.0.0.1`
- 默认只接受 `faolla.com` 和本地开发地址的网页请求
- 其他允许来源可通过环境变量追加：

```powershell
$env:FAOLLA_PRINT_HELPER_ALLOWED_ORIGINS="https://example.com"
npm.cmd run print-helper
```

## 回退

如果助手未运行，且后台开启了 `助手不可用时回退到浏览器打印`，系统会继续使用浏览器打印窗口，不影响结算。
