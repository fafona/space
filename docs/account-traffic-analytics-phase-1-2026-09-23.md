## 数据和安全边界

- 新表 `account_traffic_events`，迁移 `202609230049`。RLS 开启、撤销 anon/authenticated/public 访问，仅服务角色读写；报表复用现有超级后台域名、会话和受信设备校验。
- 公开内容服务器解析归属并签发独立 HMAC 签名，客户端不能通过 owner/label 字段改写归属。签名 1 小时有效；它不是用户身份凭证。
- 事件 UUID 与商户 ID 组合唯一，重送不会增加计数；事件时间由数据库生成。
- 一批最多 10 个事件，流式检查请求体上限，枚举动作和来源；不接收客户端时间、任意 URL、姓名、表单内容、手机号、聊天内容等。
- 不保存原始 IP/UA/referrer、持久访客 ID，不使用 cookie/localStorage/sessionStorage；来源先归类再发送。保留公开内容 ID/标题用于对象分析。
- 尊重 DNT/GPC；iframe 中不采集。产品/预约复用组件仅在公共页面 Provider 下采集，编辑器不挂载 Provider。
- 已知机器人 UA 被过滤，但不宣称能排除所有机器人。公网事件仍可能被模拟，不得作为计费或结算依据。
- IP 限流仅用于滥用控制：进程随机盐、内存哈希、一分钟桶、最多 10,000 桶，不写日志/数据库；上线需确认反向代理覆盖真实 IP 头。不是跨进程分布式限流。
- 延迟到首屏后获取上下文，批量异步提交；不无限重试、不持久排队。断网、隐私设置、拦截工具、请求限流或签名过期可能漏报，不能把浏览数当独立人数。
- 默认 `FAOLLA_TRAFFIC_ENABLED=0`。独立 `FAOLLA_TRAFFIC_SIGNING_SECRET` 至少 32 字符，不复用登录密钥或服务角色密钥。
